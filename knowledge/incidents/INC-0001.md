\# Incident INC-0001



\## Problem



API returned HTTP 500 errors after a deployment.



\## Root Cause



A database connection pool configuration change caused connection pool exhaustion.



\## Evidence



\- Database connection usage reached the configured maximum.

\- Database errors increased after deployment.

\- API HTTP 500 errors increased.

\- Latency increased.

\- Deployment modified database configuration.



\## Lesson



Temporal correlation alone should not be treated as proof of causation. Always compare configuration before and after deployment and check traffic and database health.
